# Sistema de Gestion de Inventario y Ventas

## Descripción
Sistema completo para la gestion de inventario y ventas desarrollado en python. Permite administrar productos, realizar ventas, generar reportes y mantener un historial completo de transacciones utilizando archivos de texto plano (.txt) para almacenamiento.

## Caracteristicas Principales
- Gestion completa (Registrar, Vender, Ver)
- Registro de ventas completa con resultado automatico IGV(18%)
- Validacion de entrada de datos 
- Persistencia de datos 
- Sistema de reintentos para entradas invalidas 
- Interfaz de consola amigable y facil de usar

## Requisitos del sistema 
- Python 3.7 o superior 
- Sistema operativo: Linux, Windows, MacOS
- No requiere dependencias externas (Solo bibleotecas estandar )
